# superagent-test

Sandbox repository for a dsh-superagent installation.

The agent takes requests from GitHub Issues and comments that mention it, and
answers in the same conversation with a pull request.

## 如何提需求

在本仓库的 Issue、PR 评论或项目群聊中提出需求时，必须 **@ 机器人**（GitHub 上为 @JackieLing，飞书群内为 @Super-Agent项目一组），并写清具体目标：

- **必须 @ 机器人**：没有 @ 到机器人，需求不会被受理。
- **说清具体目标**：写明要改哪里、期望什么结果，避免只写「优化一下」。
- **控制篇幅**：需求描述尽量控制在 300 字内。

例如：「@ 机器人 把 README.md 的安装步骤改成三行内，并补充一条示例。」
